# Local contract ABI contract

Sandbox-only; no production Safe deployment or compatibility certification. Solidity ABI is generated by `forge build --root contracts` into `contracts/out`.

Constructors:
- `SandboxAccount(address[3] initialOwners)` fixed 2-of-3 EOA owners.
- `MandateRegistry(address account, bytes32 groupId)`.
- `ExecutionModule(address account, address registry)`.

`ExecutionGrant` tuple order: `bytes32 intentHash, bytes32 mandateId, uint256 mandateVersion, address executor, address target, bytes4 selector, bytes32 calldataHash, address inputToken, uint256 maxInputAmount, uint256 value, uint256 validAfter, uint256 validUntil, uint256 nonce, bytes32 pluginId, uint256 minOutputAmount, uint256 chainId`.

`execute(ExecutionGrant g, bytes data, bytes signatures)`; `hashGrant(ExecutionGrant)` returns exact EIP712 digest. Domain: name `SynqExecutionModule`, version `1`, chainId current chain, verifyingContract module, salt `keccak256(abi.encode(account, groupId))`. `ExecutionGrant` type members exactly match tuple above. Signatures: two concatenated r/s/v 65-byte ECDSA signatures ordered by recovered signer ascending; sign the digest directly without personal-sign prefix.

`Mandate` tuple: `address target, bytes4 selector, address inputToken, uint256 maxPerCall, uint256 cumulativeCap, uint256 maxValue, uint256 validUntil`.
`configure(bytes32 id,uint256 version,Mandate)` and `revoke(bytes32 id)` only callable by account. Versions increment by exactly one. Spend accumulates by mandate id across supersessions; denomination is immutable within each mandate id. Grant validity is validAfter <= timestamp < validUntil (exclusive expiry), and mandate expiry is exclusive. `setPaused(bool)` only account.

Account governance: `ownerTransactionHash(address target,uint256 value,bytes data,uint256 nonce)` returns digest; `ownerExecute(address target,uint256 value,bytes data,bytes signatures)` consumes ownerNonce. Enable/disable module by ownerExecute targeting account with `setModule(address,bool)` calldata. Recovery transfers use same independent ownerExecute path even while module paused.

Native: inputToken zero, selector zero, calldata empty, maxInputAmount/minOutputAmount zero, value exact transfer. ERC20: target=inputToken, selector `0xa9059cbb`, exact 68-byte transfer calldata, value zero, decoded transfer amount equals maxInputAmount. Both account debit and recipient credit must equal amount, excluding fee tokens/rebasing tokens. No approve, swap or arbitrary calldata.

Events:
```solidity
event MandateConfigured(bytes32 indexed groupId, bytes32 indexed mandateId, uint256 indexed version, address account, address target, bytes4 selector, address inputToken, uint256 maxPerCall, uint256 cumulativeCap, uint256 maxValue, uint256 validUntil);
event MandateRevoked(bytes32 indexed groupId, bytes32 indexed mandateId, uint256 indexed version, address account);
event PauseChanged(bytes32 indexed groupId, address indexed account, bool paused);
event GrantExecuted(bytes32 indexed groupId, bytes32 indexed intentHash, bytes32 indexed mandateId, uint256 mandateVersion, address account, address executor, bytes32 pluginId, uint256 chainId, uint256 nonce, bytes32 grantHash, address target, bytes4 selector, bytes32 calldataHash, address inputToken, address recipient, uint256 inputAmount, uint256 value, uint256 outputAmount);
```
