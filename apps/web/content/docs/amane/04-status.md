## How to read the capability report

`GET /v3/workspaces/{workspaceId}/mandates` returns a `capability` with one of:

- `NOT_CONFIGURED`: the server has no agent key or pinned code hash, the workspace has no account, the account code differs from the pin, or there is no live lease.
- `ONCHAIN_AUTHENTICATED`: the contract enforces the lease; no Synq payment has been verified.
- `VERIFIED_TESTNET`: at least one Synq job reached `PAID` and was verified from the contract's `Executed` event on Arc testnet.

## Honest limits

- Amane's reviews are targeted engineering reviews, not a security audit.
- The vendored release is a local tarball set; there is no signed tag or public source verification claim.
- Synq trusts the RPC it reads from for contract state (the code identity proof is `RPC_CODE_IDENTITY`, not a light client). The contract still enforces the lease at execution time.
- Amane gives no protection against a malicious owner or a compromised owner wallet: the owner can sign any policy they like.
