# Theming the Synq iMessage extension

The whole look of the extension (screens, sheets, compact mode, transcript cards
and the design previews) comes from one value: the current `SynqTheme`.

## How it fits together

| Layer | File | What it holds |
|---|---|---|
| Theme protocol | `SynqMessagesExtension/SynqTheme.swift` | `SynqTheme` plus its token types: colours (`SynqColors`), type roles (`SynqTypography`: wordmark, title, sectionLabel, amountLarge, body, caption, mono…), spacing, radii, line widths, motion, decorative glyphs, flavour copy (taglines, tab labels), icon names, component looks, and `art(_:_:)` for the art registry. Also the `\.synqTheme` environment key and font registration. |
| Components | `SynqMessagesExtension/Components.swift` | `SynqPanel`, `SynqButton` (`.primary` / `.secondary` / `.compact`), `SynqField`, `SynqRow`, `SynqGroup`, `SynqBadge`, `SynqProgress`, `SynqAvatar`, `SynqKeypad`, `SynqTabBar`, `SynqHeader`, `SynqHeroArt`, `SynqArtStrip`, `SynqCardBubble` and friends. Each one reads the theme and asks it how to draw itself. |
| Screens | `FundViews.swift`, `DetailViews.swift`, `Sheets.swift`, `CardViews.swift`, `FundCards.swift` | Layout and functional English copy only. They never set colours, fonts, radii, SF Symbols, bracket glyphs or art; `check.sh` greps for this and fails if they do. |
| Themes | `AsciiTheme.swift` (default), `HoloTheme.swift` | Implementations of `SynqTheme`. The ASCII theme's art lives with it: `AsciiArtData.swift` is generated by `Design/ascii-art.swift`. |

The theme is chosen in exactly one place: `MessagesViewController.theme`
(`SynqThemes.all[0]`), injected at the root with `.environment(\.synqTheme, theme)`.

## Adding a theme

1. Create `SynqMessagesExtension/<Name>Theme.swift` with a `struct <Name>Theme: SynqTheme`.
   Fill in every token group. Start by copying `HoloTheme.swift`: it is short.
   - Type roles name a PostScript font family or `nil` for the system font. A
     missing family falls back to the system font with the role's `fallback` design.
   - `glyphs` are decoration only (brackets around buttons, the row arrow, the
     prompt, spinner frames). Use `nil` or empty to draw none.
   - `copy` is flavour only (wordmark, taglines, tab labels, "see all"). Every
     functional label, amount, address and approval text stays in the screens, in English.
   - `looks` picks component variants: notched or above panel labels, filled or
     outlined panels, pixel or initials avatars, outlined or capsule progress.
2. Provide the art set: implement `art(_ slot: SynqArtSlot, _ variant: SynqArtVariant)`
   for every slot (home, flights, fund, send, gift, receipt, deal, risk, agent),
   as a hero band and a card strip. Art must be decorative (`accessibilityHidden`)
   and must not use copyrighted images.
3. Register it in `SynqThemes.all` (`SynqTheme.swift`). The first entry is the default.
4. Bundle any fonts under `SynqMessagesExtension/Fonts/` with their licences, list
   them in `SynqFonts.files`, in the extension `Info.plist` under `UIAppFonts`, and
   in the extension target's Resources phase in `project.pbxproj`.
5. Preview it: `sh Design/render.sh <out-dir> <theme-id>` renders every screen,
   bubble, card and art piece with that theme (only the default theme rewrites
   the app icons).
6. Ship it: set `MessagesViewController.theme` (or reorder `SynqThemes.all`).

## Rules a theme cannot change

- Exact amounts, the network label (for example "Monad Testnet") and the execution
  mode (Duffel test, sandbox) are always shown.
- Cards and buttons never approve money. Approvals, joining and activation open the
  Synq page, where the passkey ceremony happens.
- High contrast text, VoiceOver labels in English, decorative art hidden from
  VoiceOver, and Reduce Motion respected (`SynqMotion`, `SynqScanBar`).

## Regenerating the ASCII theme's assets

- Art: `sh Design/ascii-art.sh [preview-dir]` redraws the procedural scenes and
  rewrites `AsciiArtData.swift`.
- Japanese font subset: `python3 Design/subset-jp.py <NotoSansJP[wght].ttf>`
  (needs `pip install fonttools`) keeps kana plus every Japanese character used in
  the theme files.
