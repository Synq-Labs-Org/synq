# Theming Synq on iOS

The whole look of the app and the Messages extension (screens, sheets, compact
mode, transcript cards and the design previews) comes from one value: the current
`SynqTheme`. All of it lives in the local Swift package `SynqShared`, which both
Xcode targets link; the extension itself only holds `MessagesViewController`.

## How it fits together

| Layer | File | What it holds |
|---|---|---|
| Theme protocol | `SynqShared/Sources/SynqShared/DesignSystem/SynqTheme.swift` | `SynqTheme` plus its token types: colours (`SynqColors`), type roles (`SynqTypography`: wordmark, title, sectionLabel, amountLarge, body, caption, mono…), spacing, radii, line widths, motion, decorative glyphs, flavour copy (taglines, tab labels), icon names, component looks, and `art(_:_:)` for the art registry. Also the `\.synqTheme` environment key and font registration. |
| Components | `SynqShared/Sources/SynqShared/DesignSystem/Components.swift` | `SynqPanel`, `SynqButton` (`.primary` / `.secondary` / `.compact`), `SynqField`, `SynqRow`, `SynqGroup`, `SynqBadge`, `SynqProgress`, `SynqAvatar`, `SynqKeypad`, `SynqTabBar`, `SynqHeader`, `SynqHeroArt`, `SynqArtStrip`, `SynqCardBubble` and friends. Each one reads the theme and asks it how to draw itself. |
| Screens | everything under `SynqShared/Sources/SynqShared/Features/` | Layout and functional English copy only. They never set colours, fonts, radii, SF Symbols, bracket glyphs or art; `check.sh` greps for this and fails if they do. |
| Themes | `SynqShared/Sources/SynqShared/DesignSystem/Themes/`: `AsciiTheme.swift`, `PaperTheme.swift`, `HoloTheme.swift` | Implementations of `SynqTheme`, each with its own name, summary, light or dark scheme and art. The ASCII theme's art lives with it: `AsciiArtData.swift` is generated by `Design/ascii-art.swift`. Paper and Holo draw their art in code. |
| Theme settings | `SynqShared/Sources/SynqShared/Features/Funds/ThemeSettings.swift` | The Theme sheet, opened from the palette button in the wordmark bar. Each option is previewed in its own theme. |

People choose the theme. The choice is saved on the device under `synq.theme`
(`SynqThemes.storageKey`). `SynqThemeRoot` reads it and injects it at the root
(`.environment(\.synqTheme, …)` plus the theme's color scheme), so a new choice
applies at once to every screen, sheet and bubble. The first entry in
`SynqThemes.all` is the default.

## Adding a theme

1. Create `SynqShared/Sources/SynqShared/DesignSystem/Themes/<Name>Theme.swift` with a `struct <Name>Theme: SynqTheme`.
   Fill in every token group, plus `name`, `summary` (shown in the Theme sheet) and
   `colorScheme`. Start by copying `HoloTheme.swift` or `PaperTheme.swift`: both are short.
   - `icons` only lists overrides; anything missing uses `SynqIcons.standard`.
   - Type roles name a PostScript font family or `nil` for the system font. A
     missing family falls back to the system font with the role's `fallback` design.
   - `glyphs` are decoration only (brackets around buttons, the row arrow, the
     prompt, spinner frames). Use `nil` or empty to draw none.
   - `copy` is flavour only (wordmark, taglines, tab labels, "see all"). Every
     functional label, amount, address and approval text stays in the screens, in English.
   - `looks` picks component variants: notched or above panel labels, filled or
     outlined panels, pixel or initials avatars, outlined or capsule progress.
2. Provide the art set: implement `art(_ slot: SynqArtSlot, _ variant: SynqArtVariant)`
   for every slot (home, flights, fund, send, gift, receipt, deal, risk, agent),
   as a hero band and a card strip. Art must be decorative (`accessibilityHidden`)
   and must not use copyrighted images.
3. Register it in `SynqThemes.all` (`SynqTheme.swift`). It then appears in the Theme
   sheet. The first entry is the default. The package picks the file up by
   itself; no project file change is needed.
4. Bundle any fonts under `SynqShared/Sources/SynqShared/DesignSystem/Fonts/` with their licences and list them in
   `SynqFonts.files`. They ship in the package's resource bundle inside both the app
   and the extension and are registered at launch (`SynqFonts.register()`); there is
   no `UIAppFonts` entry. Check the licence allows bundling in an app (all current
   fonts are SIL OFL 1.1; the Noto Sans JP subset keeps its own name, not the
   reserved name "Source").
5. Preview it: `sh Design/render.sh <out-dir> <theme-id>` renders every screen,
   bubble, card and art piece with that theme (only the default theme rewrites
   the app icons).
6. Optional: add the same id to the web workspace page (`apps/web/app/workspaces/theme.css`
   and `theme-picker.tsx`) so the look matches there.

## Rules a theme cannot change

- Exact amounts, the network label (for example "Monad Testnet") and the execution
  mode (Duffel test, sandbox) are always shown.
- Cards and buttons never approve money. Approvals, joining and activation open the
  Synq page, where the passkey ceremony happens.
- High contrast text, VoiceOver labels in English, decorative art hidden from
  VoiceOver, and Reduce Motion respected (`SynqMotion`, `SynqScanBar`).

## Regenerating the ASCII theme's assets

- Art: `sh Design/ascii-art.sh [preview-dir]` redraws the procedural scenes and
  rewrites `AsciiArtData.swift`.
- Japanese font subset: `python3 Design/subset-jp.py <NotoSansJP[wght].ttf>`
  (needs `pip install fonttools`) keeps kana plus every Japanese character used in
  the theme files.

## Targets and building

| Target | Product | What it holds |
|---|---|---|
| `SynqApp` | `SynqApp.app` (`com.apple.product-type.application`, `@main`) | `SynqApp/SynqApp.swift` only: app delegate (push), Safari hand-off, notification clearing. Embeds the extension. Bundle id = build setting `SYNQ_APP_BUNDLE_ID`. |
| `SynqMessagesExtension` | `SynqMessagesExtension.appex` | `MessagesViewController.swift` only (conversation routing, MSMessage cards, Safari). |
| `SynqMessages` | `SynqMessages.app` (iMessage-only container) | Kept unchanged for the existing App Store record path; see the coordination blocker `ios-app-store-record.md`. |
| `SynqShared` (local package) | static library + resource bundle | Everything else, including the app's screens (`Features/App`, `Personal`, `Business`, `Agents`, `Approvals`, `Notifications`). |

```
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project SynqMessages.xcodeproj -target SynqApp -sdk iphonesimulator build CODE_SIGNING_ALLOWED=NO
sh check.sh                                  # package build + tests, previews type-check, parser checks, lints
sh Design/render.sh <out-dir> paper          # also renders "4 App screens" from the contract fixtures (LOCAL_FIXTURE)
```

The app's default theme is Paper (`SynqThemes.defaultId`, set by the app host); the
extension keeps ASCII as its default. Both still offer every theme.
