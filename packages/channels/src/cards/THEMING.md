# Card themes

Card images are drawn in two layers:

1. **Content** (`content/`): one pure function per card type turns a canonical
   `InteractiveCard` into a theme-independent `CardContent`: type label, section,
   title, subtitle, exact headline amount, status badge, rows, note, stats,
   network and execution mode, immutable refs, an art slot with its state
   (`progress`, `count`, `tone`, `nodes`), grade and action labels. Meaning is
   carried by semantic values only: `Tone` (`ok`, `pending`, `bad`, …),
   `IconSlot` (`flight`, `signature`, …) and `ArtSlot` (`treasury` … `flight`).
   Content code never names a colour, font, glyph or piece of art; a test
   (`tests/channels/arc-cards.test.ts`) greps for that.
2. **Theme** (`themes/<id>/`): turns `CardContent` into a satori tree.

## Adding a theme

Create `themes/<id>/` exporting a `CardTheme` (see `themes/kit.ts`):

```ts
export const myTheme: CardTheme = {
  id: 'my-theme',
  width: 1000,
  height: 1400,
  fonts: (dir) => [fontFile('My Mono', 'MyMono-Regular.ttf', 400, dir)],
  render: (content) => myCard(content),
};
```

Keep the module self-contained:

- `tokens.ts`: colours, font names, sizes, spacing, radius, line weights;
- fonts in `packages/channels/assets/fonts/` with their licence (OFL or
  similar), subset to what the theme draws;
- `primitives.ts`: panel, row, button, badge, progress;
- an art registry covering every `ArtSlot` (`ART_SLOTS` in `content/model.ts`);
- `layout.ts`: the card, drawing at least the title, headline amount, rows,
  network and mode label (`content.mode.label`).

Register it in `themes/registry.ts`. That is the only shared edit: no
per-card-type code changes. `tests/channels/arc-cards.test.ts` renders every
card type with every registered theme and checks the network, mode and
headline figures appear in the tree.

## Selecting a theme

`new CardBannerRenderer({ theme: 'holo' })`, or `SYNQ_CARD_THEME=holo` for the
default renderer; unknown ids fall back to `ascii`. The image cache key
includes the theme id.

## The bundled themes

- `ascii` (default): the monochrome ASCII / dot-matrix design system
  (`reports/handoff/design/ASCII_DESIGN_SYSTEM.md`). Fonts: JetBrains Mono,
  Departure Mono and a Noto Sans JP subset (all OFL, see `assets/fonts/OFL-*`).
  Art is generated by `scripts/card-art.ts` from procedural shapes into
  `themes/ascii/art-data.ts`; fonts are subset by `scripts/card-fonts.py`
  (rerun it after changing a Japanese tagline).
- `holo`: the previous holo trading-card design, kept as a second theme.
